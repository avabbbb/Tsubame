# YUZUKI 产品指南

本文档面向最终用户，说明 YUZUKI 的功能、与 ASPlayer 的功能对照，以及日常使用方法。开发与架构说明见 README 及其他 docs。

## 1. 定位

YUZUKI 是本地优先的 ASMR / 音声作品工作台：媒体库 + 句级播放器 + 听力练习 + AI 转写/翻译/配音。所有数据保存在本机；云端 AI 使用你自己的 API Key（BYOK）。

## 2. 与 ASPlayer 的功能对照

ASPlayer（GPL-3.0）仅作为产品与交互参考；YUZUKI 的对应功能均为独立实现，未复制其源码。

| 功能 | YUZUKI 状态 | 入口 |

| 句末自动暂停 | 已实现 | 播放控制 / 快捷键 |
| 盲听（隐藏译文，按住 H 显示） | 已实现 | 播放控制 |
| 自动连播下一集 / 列表循环 | 已实现 | 播放控制 |
| 播放进度记忆 | 已实现 | 自动 |
| 导入文件 / 文件夹（递归） | 已实现 | 标签栏 + 按钮、导入文件夹 |
| 媒体库搜索与排序 | 已实现 | 侧栏媒体库 |

## 3. 安装与首次设置

1. 从 GitHub Releases 下载安装包（Windows x64 / macOS Apple Silicon / macOS Intel）。
2. 打开 设置 → 提供方，填入你要使用的云端 AI 密钥（可选）。
3. 在 设置 → 运行时包 中只安装当前处理方案需要的本地模型。下载中断后可续传，完成后会做 sha256 校验。

### 3.1 本地语音识别（faster-whisper）

本地 ASR 使用 `local.faster-whisper`，默认模型 `large-v3-turbo`。目前只提供 Windows x64 运行时包，分为两个：

- 基础包 `runtime.faster-whisper`（CPU，下载约 97.1 MB，解压后约 272 MB）：本地转写必需，自带 Python，不使用系统 Python。
- 可选包 `runtime.faster-whisper.cuda`（NVIDIA GPU 加速，下载约 1.37 GB，解压后约 2.11 GB）：仅在检测到 NVIDIA 显卡驱动时列入安装计划；不装也能用 CPU 转写。
- SenseVoice 包 `runtime.funasr`（CPU，下载约 316 MB，解压后约 1.05 GB）：选用 SenseVoice（`local.sensevoice`）转写时才需要，自带 Python，不使用系统 Python。模型 `iic/SenseVoiceSmall` 首次使用时从 ModelScope 下载。
- 设备选择默认为自动：已安装 GPU 包且显卡可用时用 GPU，否则用 CPU，并在转写结果备注中写明原因。明确指定 GPU（`YUZUKI_ASR_DEVICE=cuda`）但不可用时会报错，不会悄悄改用 CPU。
- 首次使用某个模型时，会从 Hugging Face 下载对应的模型文件（尚未做成运行时包）。
- 旧版本的本地 ASR 运行时与模型包会在启动时自动清理；仍指向旧引擎的任务会改用 faster-whisper + `large-v3-turbo` 运行，并在结果中注明。

这两个运行时包已于 2026-10-29 以 GitHub 预发布形式发布，全新安装可直接下载。尺寸与 sha256 见 docs/06-runtime-bootstrap.md。

## 4. 日常使用

### 4.1 导入与管理媒体

- 标签栏 + 按钮导入单个文件；导入文件夹会递归扫描，跳过隐藏文件、符号链接和非媒体文件。
- 媒体库支持按名称搜索和排序；上次播放位置会自动恢复。

### 4.2 转写、精修、翻译

1. ASR 面板选择引擎并运行，生成句子时间轴。
2. 可选：用 LLM 精修转写。
3. 翻译面板生成译文。所有任务在任务视图中可查看进度。

### 4.3 句级听力练习

- 点击句子跳转；当前句会高亮。
- 句末自动暂停：每句结束后暂停，适合跟读。
- 盲听：隐藏译文，按住 H 临时显示。
- 自动连播与列表循环。以上偏好会自动保存。

### 4.4 迷你字幕窗

打开后显示置顶的当前句原文与译文（遵循盲听设置）。锁定后鼠标可穿透到下方窗口；在主窗口点 Unlock 解锁。

### 4.5 快捷键

设置 → 快捷键 可重新绑定或清空任意动作，冲突会提示，可一键恢复默认。全局热键需手动开启，开启后应用在后台时也响应。

### 4.6 离线查词

YUZUKI 不自带词典数据。在 设置 → 离线词典 中导入：

- JMdict（日→英）：jmdict-simplified 的 JSON 文件，数据许可 CC BY-SA 4.0（EDRDG）。
- ECDICT（英→中）：ECDICT CSV，MIT。

导入后可在设置中直接查询，或在句子列表中用鼠标选中词语（不超过 40 字符）弹出释义。支持精确、读音和最长前缀匹配。数据保存在应用数据目录的 `dictionary.db`，可随时替换或删除；各来源的署名信息显示在对应条目下。

### 4.7 配音与导出

- 为句子生成 TTS 配音，可单句重生成。可选「Edge TTS (online)」：在设置中手动安装 runtime.edge-tts 运行时包后使用；它需要联网，并把每句译文（已去掉网址、邮箱、电话等）发送到微软的在线语音服务，不是离线语音，也不会自动启用。
- Pushed / drift 徽章提示配音被推后或超时，可缩短译文或跳过该句。
- 导出字幕或混音音频。

### 4.8 代理与命令行

桌面端运行时，`yuzuki` CLI 和 `yuzuki-mcp` 通过本地控制端点操作媒体库、任务与句子。详见 docs/07-agent-control.md。

## 5. 更新

应用启动时检查更新，也可在 设置 → YUZUKI Updates 手动检查；仅在你确认后下载安装。

## 6. 隐私与权利

- 媒体、字幕、词典和设置均保存在本机；只有你主动使用的云端提供方会收到对应文本或音频。
- 未经授权，不得用于训练、克隆或合成真实人的声音。

## 7. 已知限制

- 安装包尚未做代码签名 / 公证，系统可能提示未知开发者。
- 离线本地 TTS 运行时包（IndexTTS）尚未提供；目前可用的 Edge TTS (online) 是云端语音，输出 24 kHz，约 11 kHz 以上高频缺失。
- 词典需用户自行下载导入。
