# 2026-10 端到端中文同传配音实测：问题日志

素材：一段 18:41（1121.45 s）的日语男性向情景 ASMR 视频，H.264 720p，AAC 立体声 44.1 kHz。本地文件，未上传。
硬件：RTX 3050 Ti Laptop 4 GB（空闲占用约 1.6 GB）。
脱敏规则：本文件不写用户目录、密钥、token、素材完整文件名；路径一律写成 %LOCALAPPDATA% / %APPDATA% 形式。

每条格式：现象 / 根因 / 修复 / 验证。

## I-01 edge-tts 握手 403
- 现象：edge_tts 7.2.8 连接 speech.platform.bing.com 返回 WSServerHandshakeError 403。
- 根因：旧版本生成的 Sec-MS-GEC 版本号过期，服务端拒绝。
- 修复：经代理升级到 edge-tts 7.3.1。
- 验证：zh-CN-XiaoyiNeural 合成短句成功，24 kHz mono，2.688 s。

## I-02 CLI 报 desktop_not_running（control.json 陈旧）
- 现象：yuzuki --json app status 退出码 3，提示 %APPDATA%/…/control.json is stale。--launch 也未拉起 Desktop。
- 根因：上次 Desktop 退出未清理 control.json；debug 构建依赖 vite dev server，单独启动二进制无法起来。
- 修复：用 npm run tauri dev 启动 Desktop；待办：--launch 在 debug 构建下应给出明确提示。
- 验证：app status 返回 running，端点 127.0.0.1 随机端口。

## I-03 Registry 无法驱动完整配音链路
- 现象：yuzuki ops list 只有 segment/job/runtime/provider.list 共 9 个 op，导入、转写、翻译、TTS、混音导出只能经 GUI。
- 根因：PR #13 第一批只迁了 6 个操作。
- 修复：进行中，把 media/asr/translate/tts/spatial/dub/mix 包成 op（复用现有 job runner，不另写业务路径）。
- 验证：待填。
- 实测（2026-10-25）：本轮 TTS、空间渲染、混音导出仍由脚本直接调用 edge-tts shim 与 spatial 渲染模块完成，未经 registry op；本问题仍未关闭。

## I-04 发往云端的文本未脱敏
- 现象：翻译/润色请求与远程 TTS 请求没有任何脱敏层；仓库中不存在 redact/sanitize 函数。loopback 网关可能转发到云端。
- 根因：设计时只考虑了 API key 不出现在输出里，没考虑请求正文。
- 修复：redact.rs 接入 refine::chat_completion（翻译/润色共用：发送前 system/user 均脱敏，回答在本机 restore；key 永不还原）与 OpenAiCompatibleTts::request_body（input、instructions）。edge-tts shim 新增 workers/tts/outbound_redact.py，规则与 Rust 同序同占位符，绕过 Desktop 直调 shim 也会脱敏。人名不处理（与角色名无法区分）。
- 验证：cargo test 279 passed / 2 ignored（含 redact 单测与 request_body_sends_only_redacted_sentence_text）；python -m unittest workers/tts/tests 6/6 OK。
- 2026-10-25 实测出站抽查：260 句中文译文经 for_cloud 后 0 句被改写（字幕本身不含敏感串）；3 条合成探针（邮箱+手机号、API key 样式串、本地路径）全部被替换为占位符；shim 日志只记录请求行，不含正文。

## I-05 素材自带中文字幕质量差
- 现象：同目录 zh-Hans .srt 共 161 条，内容为机器翻译（如“我的我的[音乐]”、“没有感谢您在”）。
- 处理：不作为配音译文，只作为翻译质量对照基线。

## I-06 redact.rs 无法编译且未接线
- 现象：cargo test 报 `use super::;` 语法错；修正后又报 unresolved import `regex`、`&Kind` 类型不匹配。邮箱/路径正则量词丢失，测试里 URL 字面量被截断。
- 根因：疑似模块文件写入时被截断（URL 字面量与花括号量词丢失，未能定位到具体工具）；Cargo.toml 未加 regex；lib.rs 仅 `mod redact;` 无调用方。
- 修复：补回量词 `{0,}`、`use super::{for_cloud, Redactor}`；测试改为运行时拼接 URL；cargo add regex 1.13.1；`for &(kind, ref regex)` 解构；删未用 is_empty。
- 验证：cargo test 279 passed，无 warning。

## I-07 faster-whisper 逐句置信度相同
- 现象：large-v3-turbo 转写 270 句（68.6 s，显存峰值 3265 MiB / 基线 1874 MiB），前 5 句 confidence 均为 0.7852；首句“俺の俺のASMR”有重复。
- 根因：faster-whisper 的 avg_logprob 按一次解码窗口计算并复制给该窗口内所有句子，worker 直接用它做逐句置信度。
- 修复：transcribe 开 word_timestamps=True；新增 segment_confidence()，取本句词级 probability 均值，无词时回退 exp(avg_logprob)；单测 workers/asr/tests/test_confidence.py。
- 验证：ASR 单测 8/8。全片复跑 260 句、239 个不同置信度，中位 0.959，<0.5 的 9 句；耗时 57.5 s（首轮 68.6 s），显存峰值 3218 MiB。副作用：词级时间戳改变切句，句数 270→260。

## I-08 本地 LLM 网关 401
- 现象：GET <本地代理>/v1/models 返回 401 Missing API key。
- 根因：Desktop 尚未配置该网关 provider，系统凭据库与环境变量均无本应用的 key。
- 修复：用户经剪贴板提供网关 key，未回显，写入用户环境变量 YUZUKI_LLM_API_KEY；未复用其他应用的凭据。
- 验证：GET /v1/models 200（含 hark 等 10 个模型）；POST /v1/messages 用 probe 模型返回 400 unknown provider（key 已被接受）。日→中 3 句冒烟：OpenAI 格式 hark 200（12.8 s），Anthropic 格式 hark 200，译文一致；notion-claude-opus-5-5 返回 permission_error premium-feature-unavailable，不可用。
- 验证（2026-10-25）：网关 key 改由用户环境变量提供后，翻译 260/260 成功、0 失败、0 重试，总耗时 342.8 s；OpenAI 与 Anthropic 两种协议均已通过。

## I-09 TTS 句长被误判为约 89478 s，全部被强制 1.5 倍速
- 现象：首轮 260 句全部判定超出字幕时隙，二次合成均落到 speed 1.5；wave 模块读出的时长约 89478 s。
- 根因：ffmpeg 以管道输出 WAV 时无法回写头部，RIFF 与 data 块大小保留占位值 0xFFFFFFFF；按头部计算帧数即得到错误时长。真实时长（按 data 实际字节）首句为 1.872 s。
- 修复：edge_tts_shim 新增 fix_wav_sizes，转码后按实际字节回写 RIFF/data 大小；新增 tests/test_wav_header.py（3 个用例）。
- 验证：修复后重跑 S2c，首句 2.40 s（speed 1.14）落入 2.50 s 时隙；全量结果见下文“S2c/S2d 实测”。

## I-10 重启后的 shim 仍返回旧代码结果
- 现象：修复 I-09 后重跑，首句仍返回错误头部。
- 根因：Windows 下 Python 启动器派生子进程，terminate 只结束父进程，旧 shim 子进程继续占用原端口；新进程绑定失败，请求被旧进程处理。
- 修复：启动前按端口查杀残留监听进程（taskkill /T）；改用新端口启动并核对 stdout 的监听行；结束后再次检查端口无残留。
- 验证：新进程监听行与 proxy=set 确认，结束后残留监听进程为 0。

## I-11 edge-tts 偶发连接失败（502）
- 现象：经代理连接语音服务时偶发 ClientConnectorError / ConnectionTimeoutError，shim 按设计返回 502。
- 根因：网络/代理瞬时失败，非代码问题；4 并发时更易出现。
- 修复：调用端并发降到 2，单句最多 5 次指数退避重试；失败不伪造成功。
- 验证：最终一轮 1 句首次 502、重试成功，0 句最终失败。
